# 🎹 One Piano

A playable virtual piano built using **HTML**, **CSS**, and **JavaScript**. Users can play various tunes by clicking the keys or using their keyboard. The app also includes volume control and the ability to toggle keyboard shortcut labels.

---

## ✨ Features

- Play piano sounds using mouse or keyboard
- Adjustable volume control
- Show/hide keyboard key labels
- Responsive and interactive UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
